# 25EVO BSPD 지연회로 — 다이오드 유무 비교

사용자가 제공한 25EVO 스케메틱의 R12=10kΩ, R14=39kΩ, C8=10µF, R13=470Ω, D1=1N4148 계열을 바탕으로 만든 Falstad/CircuitJS 비교 실험이다.

## 실행

`start.html`을 브라우저에서 열어 원하는 시험 버튼을 누른다. 또는 Falstad의 **File → Import From Text**에서 아래 `.txt` 파일 내용을 붙여 넣는다. 파일 열기 메뉴로 `.txt`를 직접 불러와도 된다.

| 파일 | 입력 조건 | 관찰할 차이 |
|---|---|---|
| repeat-input.txt | 0.30초 HIGH / 0.06초 LOW 반복 | 다이오드가 없으면 잔류 전압이 누적되어 세 번째 입력에서 Fault 발생. 다이오드가 있으면 이 조건에서 Fault가 발생하지 않음. |
| long-input.txt | 1.00초 HIGH / 1.00초 LOW 반복 | 두 회로 모두 충분히 오래 지속된 입력에 반응. 다이오드가 있는 쪽은 입력 해제 후 더 빨리 복귀. |

**Reset**은 커패시터 전압을 0V로 되돌리고 시간을 다시 시작한다. **Run / Stop**으로 파형을 멈춰 관찰한다. 그래프가 작으면 회로와 그래프 사이의 가로 경계를 위로 끌어 올린다. Simulation Speed는 화면 재생 속도이며 소자값을 바꾸지 않는다.

## 화면 읽는 순서

1. 왼쪽 **A: WITHOUT diode**는 방전 다이오드와 470Ω 가지를 제거한 비교군이다.
2. 오른쪽 **B: WITH D1 + R13**는 원본과 같은 빠른 방전 가지를 갖는다.
3. 맨 아래 왼쪽 INPUT은 두 센서가 모두 임계값을 넘은 조건을 나타낸다. HIGH=위험 조건 성립, LOW=조건 해제. 양쪽 입력원은 주파수·듀티·위상이 같아 동기화되어 있다.
4. 가운데 CAP 그래프는 녹색=A의 C8 전압, 빨간색=B의 C8 전압, 주황색=3.6V 기준이다.
5. 오른쪽 OUTPUT 그래프에서 **낮은 출력이 Fault**다. 반복 입력 시험에서 낮아지는 선은 A이고, 높은 상태를 유지하는 선은 B다. 이것은 지연 비교기 출력이며 10초 유지/래치의 최종 출력은 아니다.

## 왜 차이가 생기나

입력이 HIGH이면 앞단의 오픈 컬렉터 등가 스위치가 열린다. C8은 +5V → R12(10kΩ) → R14(39kΩ) → C8 경로로 충전된다. 이때 D1은 역바이어스되어 방전 가지에 거의 전류가 흐르지 않는다.

충전 시정수는 `(10kΩ + 39kΩ) × 10µF = 0.49s`다. **시정수 0.49초와 Fault까지의 시간은 같지 않다.** 0V에서 3.6V에 도달하는 시간은 `−0.49 ln(1−3.6/5) ≈ 0.624s`다.

입력이 LOW이면 오픈 컬렉터 등가 스위치가 닫혀 앞 노드를 GND 쪽으로 당긴다.

- **다이오드 없음:** C8은 주로 R14=39kΩ을 통해 방전된다. 방전 시정수는 약 0.39초이므로 0.06초 휴지기에는 전압이 많이 남는다. 다음 입력은 0V가 아니라 남은 전압에서 시작한다.
- **다이오드 있음:** C8 → R13=470Ω → D1 → 풀다운 경로가 열린다. 주 방전 구간이 훨씬 빨라지며 다음 입력의 시작 전압이 낮아진다. D1의 **캐소드(막대 쪽)는 풀다운 노드, 애노드는 C8 쪽**이다.

`470Ω × 10µF = 4.7ms`는 빠른 방전 구간의 대략적인 시간 규모다. 실제 모델에는 스위치 저항과 다이오드의 비선형 전압강하가 있어 완전 방전 시간을 이 숫자로 단정할 수 없다. 다이오드가 있어도 즉시 0V가 되는 것은 아니며, OFF 시간이 극단적으로 짧으면 잔류 전압을 항상 제거한다고 보장할 수 없다.

## 발표용 설명

“두 회로의 충전 속도는 거의 같습니다. 차이는 위험 조건이 해제된 다음입니다. 다이오드가 없으면 커패시터가 천천히 방전되어 짧은 입력도 반복되면 전압이 누적됩니다. 25EVO의 다이오드와 470Ω은 빠른 방전 통로를 만들어 이 누적을 줄입니다. 따라서 핵심 효과는 지연시간을 줄이는 것이 아니라, 연속 입력 판정의 초기 상태를 빠르게 회복하는 것입니다.”

## 모델의 범위

- 원본 지연 경로의 저항·커패시터 값을 유지했다. 1N4148WS 패키지의 정밀 모델 대신 CircuitJS의 1N4148 모델을 사용했다.
- 앞단 LM339의 두 센서 비교기와 Wired-AND는 HIGH일 때 개방되는 등가 스위치로 치환했다. 도통 저항은 20Ω이다. HIGH를 RC 노드에 직접 강제하지 않아 R12의 충전 저항 기여를 보존했다.
- 지연 판단 기준은 고정 3.6V로 단순화했다. 원본 R15=39kΩ / R16=100kΩ의 분압 및 R17=1MΩ 양의 되먹임을 그대로 구현한 정밀 LM339 모델은 아니다. 실제 원본의 상승·하강 임계값과 시간은 이 예시와 조금 달라질 수 있다.
- 센서 단선 검출, 10초 유지, SDC 구동, 온도·공차·입력 공통모드 범위는 이 실험의 대상이 아니다. 수치는 이 교육용 모델의 결과이며 하드웨어 실측값이 아니다.
