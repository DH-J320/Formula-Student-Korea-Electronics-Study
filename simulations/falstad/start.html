방전 다이오드 유무 비교

Falstad에서 같은 지연회로를 나란히 비교합니다.
A: 다이오드 없음 / B: D1 + 470Ω 있음

연속 입력 시험

1초 HIGH / 1초 LOW 조건입니다. 두 회로 모두 충분히 긴 입력에서 Fault를 내고, 입력이 해제되면 다이오드가 있는 B가 더 빠르게 회복하는 모습을 볼 수 있습니다.

Falstad 회로 열기 ↗

반복 입력 시험 파일

0.30초 HIGH / 0.06초 LOW 반복 조건은 repeat-input.txt에 저장했습니다. Falstad의 File → Import From Text에서 파일 내용을 붙여 넣으면 됩니다. 이 조건에서는 다이오드 없는 A의 C8 전압이 누적되어 세 번째 입력에서 3.6V를 넘고, B는 임계값 아래에 머뭅니다.

파형 읽기

가운데 CAP 그래프에서 녹색은 A의 C8, 빨간색은 B의 C8, 주황색은 3.6V 기준입니다. 오른쪽 OUTPUT 그래프에서는 LOW가 Fault입니다.

충전 시정수는 (10kΩ+39kΩ)×10µF=0.49초이고, 0V에서 3.6V까지는 약 0.624초입니다. 다이오드가 있으면 입력 해제 시 C8→470Ω→D1 경로로 빠르게 방전됩니다.

제공된 25EVO 스케메틱 기반 교육용 모델. LM339 앞단은 오픈 컬렉터 등가 스위치, 판정 기준은 고정 3.6V로 단순화했습니다. 10초 유지/래치 회로는 포함하지 않습니다.
