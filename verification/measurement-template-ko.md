# BSPD 측정 기록 양식

실제 시험 결과를 아직 채우지 않은 양식이다. 교육용 시뮬레이션 결과를 실측으로 옮겨 적지 않는다.

## 시험 조건

| 항목 | 기록 |
|---|---|
| 차량·PCB 리비전·실제 BOM | 미측정 |
| 날짜·계측기·프로브 | 미측정 |
| 전원 전압·온도·센서 모델 | 미측정 |
| 센서 입력 분압·외부/내부 측정 위치 | 미측정 |
| 오실로스코프 트리거·시간축 | 미측정 |

## 순서

1. HV 구동과 분리한 LV 시험 구성에서 전원·정상 출력·기준전압 확인.
2. 각 센서를 단독 변화시켜 판정 전압·히스테리시스 기록.
3. 동시 위험 입력을 지속시간 경계 전후로 바꾸고 입력과 출력을 동시에 기록.
4. 0.30초 ON/0.06초 OFF 반복 등에서 RC 잔류전압 또는 타이머 취소 확인.
5. 센서 범위 이탈이 0.5초 지연을 우회하는지 확인.
6. Fault 해제 후 10초 이내 재발시키고 연속 정상 시간 재시작 확인.
7. Fault 유지 중 RESET, 정상 복귀 후 RESET, 전원 상실·재투입 확인.
8. 최종 SDC 연계 시험에서 AIR 개방과 표시등까지 추적.

| 시험 ID | 입력 파형·조건 | 기대 결과 | 관측 결과 | 판정 | 파형 파일 |
|---|---|---|---|---|---|
| T01~T16 | [시험 매트릭스](./test-matrix.md) 참고 | 조건별 명시 | 미측정 | 미판정 | 없음 |

단선 시험은 커넥터에서 실제 분리하여 확인한다. 단순히 입력을 0V로 만드는 시험과 단선으로 노드가 floating되는 시험은 구분한다.
